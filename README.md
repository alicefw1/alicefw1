## 关于我 · About Me

目前关注计算机视觉，尤其是三维重建、多视图几何，以及把复杂模型做成可交互、可验证的系统。

*My current focus is computer vision, especially 3D reconstruction, multi-view geometry, and interactive systems that make complex models legible and testable.*

- **现在 · Now** — 用可交互的方式理解三维视觉：从相机模型、点云 / 深度到动态场景重建。
- **方法 · Approach** — 从论文、几何推导到可运行的原型，尽量把每个概念做成能操作、能验证的作品。
- **开放 · Open** — 欢迎 Issue、PR，或关于计算机视觉 / 三维重建 / 可视化的交流。

## 研究方向 · Research Focus

| 方向 | 关注点 |
| --- | --- |
| **三维重建 · 3D Reconstruction** | 多视图 / 单目几何、点云与深度、动态场景 |
| **多视图几何 · Multi-view Geometry** | 相机模型、位姿估计、三角化与对齐 |
| **交互式视觉 · Interactive Vision** | 把论文中的接口与算法做成可操作、可验证的系统 |
